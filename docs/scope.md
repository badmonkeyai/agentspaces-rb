# Scope

Written for: Ruby developers who build with agentspaces-rb.

Built: the wire peer (`tcp`, `tls`, `ws`, `wss`, `http`, `https`, session attestation on the unattested bindings, join by GroupID with the four founding checks, revocations, the claim lattice, agent identities and the two-key rule, blocks, relay paths), entries, the space verbs, the agent DSL with every verb the Python binder runs (take, notify, bid, ballot, decision, propose, LOCAL join) and every return convention, the capability clients, beacon documents (an unsigned one is refused unless `allow_unsigned: true`, as Java's reader does from 0.5.0, and a signed one unless it arrives as exactly its canonical JSON with its signature and key in padded standard base64, HLC round seven, 2026-11-08), invite keys and bootstrap, the shared fleet YAML, the CLI, the Rails, RubyLLM, and MCP gems, and the JRuby face. Not built yet: a listener or serving half (a Ruby process cannot be a seed; the Node host is the one-command seed), the content swarm beyond the tree fetch of the persistent trees (a Ruby peer fetches nodes and never serves them, never spills a large card, and resolves a stub only through an attached spill store), the gossip-learning learner, RBS signatures, and the Active Job adapter. The ordered verbs bind on the JRuby face only; there `fleet.ordered("payments", members: peer_ids)` forms each node's member of the ordered log.
